The Core Engine

Random Forest Ensemble Methodology

Tranch.ML utilizes a high-dimensional Random Forest algorithm, aggregating predictions from 500+ unique decision trees. By employing Bootstrap Aggregating (Bagging), the model effectively isolates fraudulent signals from standard user behavior, ensuring accuracy even in high-variance transactional environments.

This ensemble approach minimizes false positives (Type I errors) while maintaining a strict posture against complex spoofing attempts.

Spatial Intelligence

Geospatial Triangulation

Our algorithm implements Spherical Geometry calculations to determine the "Impossible Travel" metric. By comparing the Great-Circle Distance between the current IP origin and the last authorized handshake, Tranch.ML flags transactions that defy physical velocity constraints.

Latency analysis of the TCP/IP stack further validates if the user is masking their true location via low-quality proxy networks.

The Tranch Advantage

High Precision

Multi-tree decision paths eliminate individual model bias, isolating high-risk patterns without penalizing legitimate high-value transactions.

ONNX Optimization

Models are exported via Open Neural Network Exchange for sub-100ms inference, ensuring zero latency during the checkout flow.

Feature Weighting

Analyzes 40+ vectorized features including Device ID entropy, transaction frequency (velocity), and Z-score spending deviations.

Adaptive Posture

Dynamic thresholding allows the engine to adjust sensitivity based on global risk levels and merchant-specific historical data.
